# Keyboard shortcuts

The shortcuts `app/Dewline/MainMenu.swift` puts in the menu bar, written here by `MainMenuTests`.

| Command | Menu | Shortcut |
| --- | --- | --- |
| Settings… | Dewline | ⌘, |
| Hide Dewline | Dewline | ⌘H |
| Hide Others | Dewline | ⌥⌘H |
| Quit Dewline | Dewline | ⌘Q |
| New | File | ⌘N |
| New Tab | File | ⌘T |
| Open… | File | ⌘O |
| Open Folder… | File | ⌥⌘O |
| Quick Open… | File | ⇧⌘O |
| Close | File | ⌘W |
| Save | File | ⌘S |
| Undo | Edit | ⌘Z |
| Redo | Edit | ⇧⌘Z |
| Cut | Edit | ⌘X |
| Copy | Edit | ⌘C |
| Paste | Edit | ⌘V |
| Select All | Edit | ⌘A |
| Find… | Edit › Find | ⌘F |
| Find in Files… | Edit › Find | ⇧⌘F |
| Find Next | Edit › Find | ⌘G |
| Find Previous | Edit › Find | ⇧⌘G |
| Go to Line… | Edit | ⌘L |
| Command Palette… | View | ⇧⌘P |
| Show Sidebar | View | ⌃⌘S |
| Show Source | View | ⌥⌘U |
| Minimize | Window | ⌘M |
| Welcome to Dewline | Window | ⇧⌘1 |
