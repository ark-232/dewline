# Welcome to Dewline

Dewline edits the Markdown files you already keep, where they are. This guide is one of them: type anywhere, and it saves as plain Markdown. A `#` starts a heading, `**bold**` and `*italics*` style as you type, `- ` starts a list and `- [ ] ` a task. ⌥⌘U shows the source, and Help > Keyboard Shortcuts lists the rest.

To open your own notes, use Open Folder… (⌥⌘O). Any folder or Obsidian vault opens as it is.

## When a file changes outside Dewline

When git, a sync app, a script or an agent changes a file you have open, you see each change here and decide: Keep or Revert. In a few seconds, a demo writer will edit the paragraph below.

This paragraph is plain text in a Markdown file on your Mac. Any app can read it, and any app can change it.

## Try it with your agent

Ask your agent to edit this file:

```text
Add one sentence to the paragraph that starts "This paragraph is plain text" in "{path}".
```

Dewline has no account and sends nothing anywhere. Your files stay where they are.
