# Welcome to Dewline

This note is a file: Welcome.md, in the Dewline folder in Documents. Type anywhere. It saves as you go.

- New note: ⌘N
- Find a note: ⇧⌘O
- Open another folder: ⌥⌘O
- Preview beside the text: ⌥⌘P
- Chat with your coding agent: ⌥⌘A

When git, a sync app or an agent changes a note, Dewline marks each change so you can keep or revert it. ⌘-click to try it: [Show me a change](dewline://demo)

Delete this note when you're done with it.
