  • Live. An outside write lands in the open file while you watch.
  • Named. Each change carries its writer's color and name.
  • Still. Your cursor, selection and scroll stay where they were.
  • Snapshot first. Dewline keeps the old text before a change lands.
  • Exact saves. Bytes you did not edit never change.

Named writers

Each writer has a color, a name and an underline. When Dewline cannot prove who changed the file, it says Unknown app. New text is washed and underlined; removed text is struck and dimmed, so the difference never rests on red and green.

Revert theirs, keep yours

Revert puts back what the agent replaced and keeps what you typed since. Every change has its own Keep and Revert, and Revert can be undone.

Plain files

Dewline opens any .md file where it lives, from Finder or the terminal. No library, no import step, no account. Obsidian vaults open as folders: wikilinks, embeds, callouts and front matter render in place, and Dewline's marks never enter the file.

The agent reads your decisions

Every Keep and Revert is recorded per session. Before its next edit, the agent can read what you kept and what you sent back.

$ dewline changes --json   # kept and reverted changes, per session
$ dewline mcp              # the same list, as an MCP server
$ dewline doctor --install-hooks   # names Claude Code's edits
