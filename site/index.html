Write in the Markdown files you already keep.

Dewline is a native Mac editor for any folder of .md files, Obsidian vaults included. It renders as you type, saves only what you change, and shows you when git, a sync app or a coding agent edits the note you have open.

Download for macOS 26

Or install with Homebrew

$ brew install --cask ark-232/tap/dewline

Free, with no account and no telemetry. Runs on Apple Silicon and Intel.

Bring the folder you already have.

Dewline opens a file where it lives and saves it there. It keeps no library, no database and no copy of your notes. Point it at a folder, a git repo or an Obsidian vault, and wikilinks, embeds, #tags, callouts and front matter work the way they already do.

There is nothing to import, and nothing to export if you leave.

A Mac app, built as one.

Dewline is AppKit and TextKit 2 over a Rust engine. There is no Electron, no web view, and no JavaScript runs on your notes. Menus, tabs, the sidebar and Quick Look behave like the rest of your Mac.

Measured for 0.1.0 on an M4 Pro, a keystroke reaches the screen in 8.9 ms at the median on a 1 MB file, and the app uses no CPU while it sits idle.

Know when something else edits the note.

Your notes live in git repos, sync folders and agent workspaces, so other things write to them. Dewline merges each outside change into the open window without losing your unsaved edits or your undo history.

A coding agent's change carries its name and its own color, and you keep it with ⌘↩ or revert it with ⌥⌘⌫. Before an outside change lands, Dewline takes a snapshot, and File > Snapshots brings it back.

Everything ships in the app

There are no plugins to find, update or trust.

Writing
Live rendering that hides syntax until the caret reaches it. Tables, task lists, footnotes, callouts, highlights, front matter and highlighted code. Math and Mermaid diagrams, drawn natively.
Finding things
Wikilinks, embeds and #tags. A folder sidebar and tabs. Quick Open (⇧⌘O), find in files (⇧⌘F) and a command palette (⇧⌘P).
Files and saves
Saves in place as plain Markdown, changing only the bytes you edited, and never over a newer copy on disk. A snapshot before every outside change.
Look and modes
Six themes and a pack of four more, in light and dark. Fonts you install from Settings. A Source view, Vim mode, and focus and typewriter modes.
Sharing
Export to HTML, PDF and DOCX. Quick Look previews in Finder. Live co-editing by invite link, peer to peer, while you are both online.

For developers

The app carries a dewline command at Dewline.app/Contents/Helpers/dewline. Use it as $EDITOR, open a file at a line, export without a window, or serve a folder's notes to an agent over MCP.

Agent hooks run dewline notify, which is how a coding agent's change gets its name. The hooks guide has the settings for Claude Code, Codex and Cursor.

# use Dewline as $EDITOR
$ export EDITOR="dewline open --wait"
# open a file at line 12
$ dewline open notes/plan.md:12
# write a DOCX beside the file
$ dewline export notes/plan.md --to docx
# serve a folder's notes over stdio
$ dewline mcp ~/notes

Your first five minutes

  1. Drag it into Applications

    Open the disk image and drag Dewline into Applications. There is no account to create, and the app updates itself after that.

  2. Watch the welcome note change

    Dewline opens Welcome.md. A few seconds later a writer named Demo edits it, so you see how an outside change is marked and how you keep or revert it.

  3. Open your own notes

    File > Open Folder (⌥⌘O) opens any folder or Obsidian vault where it is. Nothing is imported or copied.
