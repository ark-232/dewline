A Mac app, built as one.

Dewline is AppKit and TextKit 2 over a Rust engine. No Electron, no web view, and no JavaScript runs on your notes. Menus, tabs, the sidebar and Quick Look work the way the rest of your Mac does.

Your files stay your files.

Dewline opens any .md file where it lives: a folder, a git repo, an Obsidian vault. Saves change only the bytes you edited and never overwrite a newer copy on disk. Every write takes a snapshot first, and File > Snapshots restores any of them.

The features are built in.

Links, embeds, math, diagrams, export and live collaboration come with the app. There is no plugin to find, update or trust.

What is in the app

Writing

  • Live rendering: syntax hides until the caret reaches it
  • Tables, task lists, footnotes, callouts, highlights and front matter
  • Math and Mermaid diagrams, drawn natively
  • Code highlighting

Links and finding things

  • Wikilinks, embeds and #tags
  • A sidebar for the folder, and tabs
  • Quick Open and a command palette (⇧⌘P)
  • Find in files

Files and saves

  • Any folder or Obsidian vault, opened in place
  • Saves that change only what you edited
  • A snapshot before every write, restored from File > Snapshots
  • When something else changes the open file (git, a sync app, a script or a coding agent), Dewline marks each change and lets you keep or revert it

Look and modes

  • Six themes and installable fonts
  • A Source view and Vim mode
  • Focus and typewriter modes

Sharing

  • Export to HTML, PDF and DOCX
  • Quick Look previews in Finder
  • Live collaboration by invite link, peer to peer, while both of you are online

Dewline is Mac only and has no mobile app. If you need your notes on a phone, keep Obsidian or Notion for that and open the same files in Dewline on your Mac.

For developers

The app carries a dewline command at Dewline.app/Contents/Helpers/dewline. It opens files at a line, waits like an editor should, exports without a window, and serves a folder's notes to an agent over MCP.

Agent hooks run dewline notify, so a change from a coding agent carries its name. The hooks guide has the settings for each one.

# use Dewline as $EDITOR
$ export EDITOR="dewline open --wait"
# open a file at line 12
$ dewline open notes/plan.md:12
# write a DOCX beside the file
$ dewline export notes/plan.md --to docx
# serve a folder's notes over stdio
$ dewline mcp ~/notes
