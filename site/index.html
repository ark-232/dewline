Notes you can grep.

Dewline is a Mac editor for the Markdown files you already keep, in a plain folder or an Obsidian vault. It edits them where they sit and saves only what you changed.

Download for macOS 26

Homebrew

$ brew install --cask ark-232/tap/dewline

Free, with no account and no telemetry.

Bring the folder you have.

Open a git repo or an Obsidian vault and start typing. Your wikilinks still work, and Dewline keeps no copy of its own, so there's nothing to export if you leave.

A Mac app, built as one.

AppKit and TextKit 2 over a Rust engine. A keystroke reaches the screen in 9.8 ms on an M4 Pro (median, 1 MB file), and an idle window uses no CPU.

Other things write to your notes.

A git pull can change a note while you're typing in it. Dewline merges the change, leaves your undo history alone and marks it until you keep it (⌘↩) or revert it (⌥⌘⌫).

It all ships in the app.

Writing
Syntax hides until the caret reaches it. Math and Mermaid, drawn natively.
Finding
Quick Open, find in files, wikilinks, #tags.
Saving
Plain Markdown in place, never over a newer copy.
Sharing
PDF, HTML and DOCX export. Live co-editing by link.

For developers

The app carries a dewline command: make it your $EDITOR, open a file at a line, or serve a folder to an agent over MCP (hooks guide).

$ export EDITOR="dewline open --wait"
$ dewline open notes/plan.md:12
$ dewline mcp ~/notes

Open a folder.

On first launch a writer called Demo edits the welcome note, so you see a change land before your own files are involved.
