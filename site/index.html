Notes that stay files.

Dewline is a Markdown editor for Mac. Open a folder of notes or an Obsidian vault and write. Each note stays a plain .md file you can see in Finder.

Download Dewline 0.1.0 See it work

macOS 26 or later. Free, no account.

brew install --cask ark-232/tap/dewline

See your Markdown as you type.

Headings, lists, tables, math and diagrams render in place. Open the preview beside the text when you want the finished page. It scrolls with you.

Your folder is the library.

The sidebar shows the folder you opened, under its own name. Make, rename and move notes there, and Finder sees the same files. Nothing is imported.

See what changed in a note.

When git, a sync app, a script or a coding agent changes a note, Dewline marks each change. Keep it or revert it, one at a time or all at once.

Talk to your own agent beside the note.

Open the agent panel and chat with the agent you already use, such as Gemini CLI, Claude Code or Codex. Its edits arrive as marked changes. Dewline ships no model and needs no account.

Links show where they go.

A link on its own line becomes a card with the page’s title and picture. Hover any other link to see the same preview. You can turn previews off.

Write together, Mac to Mac.

Send an invite link. You approve each person by name, then you both edit the same note.
