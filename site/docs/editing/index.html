Editing

Dewline renders Markdown in place as you type. Rendering changes how characters look, never which characters are in the file.

Live rendering

Type **bold** and the asterisks hide, leaving bold text. Move the caret onto the word and they come back. Only the span under the caret shows its markers; a selection shows every span it touches.

A diagram, a $$ formula, an image alone on its line and front matter draw as a picture until the caret moves in. If one fails to draw, its source shows with the error under it.

Settings > Editor > Heading style offers Standard and Editorial. Editorial sets the first heading as a display title and section heads in small caps.

Preview beside the text

View > Preview ⌥⌘P opens the finished page in a pane on the right, with every marker hidden. The text on the left switches to Source while the pane is open. The preview scrolls with you and updates when you pause.

The same pane holds the Agent panel and the Changes list. Close it with the same key.

Source view

View > Show Source ⌥⌘U shows every character, in the code font. The caret's line stays where it was on screen.

Links

A link shows in the text color with a thin underline. ⌘-click follows it:

  • A web or mail address opens in its app.
  • A link or wikilink to a note opens the note, at the heading if it names one. A wikilink to a missing note offers to make it.
  • A footnote reference jumps to its definition and back. Hover it to read the footnote.
  • A tag runs Find in Files for it.

A web address alone on its line shows as a card with the page's title and picture. Hover any other web link to see the same preview. The file keeps the plain address either way.

Previews ask the site for its title and picture. Turn them off in Settings > Editor > Link previews; Security and privacy says what is sent. Go > Back ⌘[ and Forward ⌘] retrace your jumps. Other schemes, such as javascript: or file:, do nothing.

Lists and tasks

In a list, ↩ starts the next item, counting on or adding an unchecked box. ↩ on an empty item ends the list. ⇥ and ⇧⇥ indent and outdent every selected item, as one undo step. Click a task box to check it.

Outside a list, ⇥ types a tab or 2 or 4 spaces, as Settings > Editor > Tab key says.

Format and move lines

The Format menu writes the Markdown. Bold, Italic, Strikethrough, Highlight and Inline Code wrap the selection or the word at the caret, and unwrap it when it has the markers. Link ⌘K writes [text]() with the caret inside the parentheses.

Headings, Quote, the lists and Task act on every selected line, and come off when all lines have them. Edit > Move Line Up ⌥⌘[ and Down ⌥⌘] move the selected lines. Keyboard lists every key.

Paste images

Paste or drop an image and Dewline saves it as image-<date>-<n>.png beside the note, then links it at the caret. Settings > Files can put images in an attachments folder instead.

Find

Find… ⌘F finds and replaces in the open note. ⌘G and ⇧⌘G step through matches. Go to Line… ⌘L jumps by number.

Find in Files… ⇧⌘F searches every note in the folder, in the sidebar. Matches come grouped by note, up to 10,000. ↩ opens one, ⌘↩ opens it in a new tab, and ⎋ returns to the folder.

Focus, typewriter and motion

  • View > Focus ⇧⌘D dims every block but the caret's.
  • View > Typewriter keeps the caret's line in the middle of the window.
  • Settings > Editor > Motion sets how the caret travels on a far jump: Off, Calm or Lively. With Reduce Motion on in macOS, it is Off.

Folding

View > Fold ⌥⌘← folds the code block or callout at the caret, or else the section under the heading above. Unfold is ⌥⌘→; add ⇧ for all. A chevron in the margin folds too, and moving the caret into folded text opens it.

Spelling, Writing Tools and word count

  • Spelling is checked as you type. Code, math, front matter, HTML, addresses and wikilink targets are skipped.
  • Smart Punctuation curls quotes and turns double hyphens into dashes. It is off by default and never touches code.
  • Writing Tools and dictation work as in any Mac text view, and skip the same ranges as spelling.
  • The word count sits in the status bar under the text: “1,204 words”, or “38 of 1,204 words” with a selection. Markup and code don't count.

Note

While an input method is composing, such as Japanese or Chinese input, Dewline restyles nothing and lands no outside change.

Vim mode

Turn it on in Settings > Editor or the command palette. The mode shows at the window's lower right. In insert mode every key but ⎋ types as usual.

Undo

Each Format command, line move, file action and Keep or Revert is one undo step, named in the Edit menu. A change from another app lands without clearing your undo history.

Command palette

View > Command Palette… ⇧⌘P runs any command in the menu bar. It also changes Theme, Appearance, Smart Punctuation, Vim Mode, Heading Style and Show Ignored Files in place. Commands you ran lately rank first, and ⎋ steps back out.

Settings

Dewline > Settings… ⌘, opens on the pane you used last. Changes apply at once.

AppearanceThemes, fonts, text size, line height, line width
