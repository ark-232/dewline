Guide

Editing

Dewline renders Markdown in place as you type. The file underneath stays plain text: rendering changes how characters look, never which characters are there.

Live rendering

Markup hides once it has done its job. Type **bold** and the asterisks disappear, leaving bold text. Move the caret onto that word and the asterisks come back, so you edit the source exactly where you are and nowhere else.

The rule is per span. Only the markers of the span the caret touches show; the rest of the line stays rendered. A selection reveals every span it touches. This holds for headings, quotes, emphasis, links, inline code, highlights, wikilinks, footnote references and inline math. A tag keeps its # in sight and shows dimmed.

Some blocks draw as a picture while the caret is outside them, and show their source when the caret moves in:

  • a fenced mermaid diagram
  • a $$ formula on lines of its own
  • an image alone on its line
  • front matter, which folds to one line such as "Front matter · 3 fields"

Diagrams and math render natively, off the main thread. If one fails, Dewline shows its source with a dim line naming the error. Fenced code sits in a well in the code font, with syntax colors; its fence lines show when the caret reaches them.

Note

While an input method is composing text, such as Japanese or Chinese input, Dewline restyles nothing and applies no outside change until the composition ends.

Heading style

Settings > Editor > Heading style offers Standard and Editorial. Editorial sets the first heading as a display title and section heads in small caps. The file stays plain Markdown either way.

Source view

View > Show Source ⌥⌘U switches the window between the rendered page and the plain text, with every character visible and the whole page in the code font. The caret's line stays where it was on screen. Settings > General > Open documents in sets whether new windows start in Live or Source.

Typing, spelling and Writing Tools

  • Spelling is checked as you type, on by default. Code, math, front matter, HTML, web addresses and wikilink targets are skipped.
  • Smart Punctuation turns straight quotes into curly ones and double hyphens into dashes. It is off by default and never touches code. Turn it on in Settings > Editor or Edit > Smart Punctuation.
  • Writing Tools, dictation and the system services work as they do in any Mac text view. Writing Tools leave the same ranges alone as the spelling checker.
  • The word count sits in the line above the text, after the file's path: plans / v2.md · 1,204 words. With a selection it reads "12 of 1,204 words". Markup, code, math, front matter, HTML and link addresses don't count.

Lists and tasks

In a list item, ↩ starts the next item: a numbered item counts on by one, and a task item starts unchecked. ↩ on an empty item ends the list.

⇥ indents and ⇧⇥ outdents every item the selection touches, as one undoable edit. Outside a list, ⇥ inserts a tab or 2 or 4 spaces, as Settings > Editor > Tab key inserts says.

A click on a task box checks or unchecks it and leaves the caret where it was.

Formatting and moving lines

The Format menu writes Markdown for you. Bold ⌘B, Italic ⌘I, Strikethrough, Highlight and Inline Code wrap the selection, or the word at the caret, and unwrap it when it already has the markers. Link ⌘K writes [text]() and puts the caret between the parentheses.

Headings, Quote, Bulleted List, Numbered List and Task act on every selected line. When all the lines have the format it comes off; otherwise the lines without it get it. Numbered List numbers the lines from 1. Body Text ⌘0 turns a heading back into plain text.

Edit > Move Line Up ⌥⌘[ and Move Line Down ⌥⌘] swap the selected lines with the line above or below. The selection moves with them.

Pasting images

Paste or drop an image and Dewline saves it as a PNG named image-<date>-<n>.png, then links it at the caret, as one edit. It goes beside the document, or in an attachments folder beside it if Settings > Files says so. Save a new document once before you paste; until then it has no folder.

Focus and typewriter

View > Focus ⇧⌘D
Dims every block but the one holding the caret. Only the color changes; the text does not.
View > Typewriter ⇧⌘T
Keeps the caret's line in the middle of the window. The first and last lines can scroll to the middle too.

Settings > Editor > Motion sets how the caret travels to a far jump: Off, Calm (streaks to where a jump such as Find Next lands) or Lively (also for clicks and long moves). With Reduce Motion on in macOS, Dewline uses Off.

Folding

View > Fold ⌥⌘← folds the fenced code block or callout holding the caret, or else the section under the nearest heading above it. A heading's section runs to the next heading of the same or a higher level. Unfold ⌥⌘→ opens it again, and Fold All and Unfold All add ⇧.

A chevron appears in the left margin beside a foldable block under the pointer; click it to fold. Moving the caret into folded text unfolds it.

Following links

⌘-click follows what is under the pointer:

  • A web or mail address opens in its app.
  • A link or wikilink to a note opens the note, at the heading if the link names one. A wikilink to a note that doesn't exist yet offers to create it.
  • A footnote reference jumps to its definition, and the definition's label jumps back. Hovering a reference shows the footnote's text.
  • A tag runs Find in Files for it.

Go > Back ⌘[ and Forward ⌘] retrace the jumps. Links with any other scheme, such as javascript:, data: or file:, and absolute paths only beep.

Find

Edit > Find > Find… ⌘F opens the find bar over the page. It finds and replaces in the open file. Find Next ⌘G and Find Previous ⇧⌘G step through the matches. Go to Line… ⌘L moves the caret to a line by number.

Find in Files… ⇧⌘F searches every Markdown file in the window's folder, in the sidebar:

  • It searches as you type, once you pause, with Match Case and Whole Word switches.
  • Matches arrive grouped by file, each on its line with the match marked. A search stops at 10,000 matches and says so.
  • ↩ opens the selected match, ⌘↩ opens it in a new tab, and ⎋ returns to the file tree.

Vim mode

Turn it on in Settings > Editor or from the command palette. It is off by default. The mode shows at the window's lower right. In insert mode every key but ⎋ types as usual, and input methods keep working.

Undo

Each Format command and each line move is one step of undo, named in the Edit menu. A change made outside Dewline lands without clearing your undo history, so ⌘Z still walks back through your own edits. Files and saves covers outside changes.
