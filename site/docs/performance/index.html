Performance

Each release is held to fixed ceilings for typing, launch, opening, idle use and download size. The release workflow refuses a tag whose measured run misses any of them.

Measured numbers

Measured numbers will appear once a clean run on the signed release build exists. The 0.1.0 run used an unsigned build on a busy Mac, so it is not published.

Budgets

Each budget is a ceiling in perf/budgets.jq. A measurement that is missing misses its budget.

BudgetCeiling

A megabyte means 1,048,576 bytes. Scrolling has no budget here; it is measured in Instruments.

What each budget measures

Keystroke
The caret sits in a styled span mid-document. The test types a and Delete 150 times each. Each sample runs from key down through layout, display and the Core Animation commit.
Cold launch
A fresh copy of the app and the 1 MB document, both copied past the file cache with ditto --nocache. It launches three times, timed from process start to the window's first display.
Warm launch
The app opens the 1 MB document once unrecorded, then five more times. The median counts.
Open
Setting the text and drawing the first screen. Styling the rest continues after it.
Idle
The app opens the document and waits until its CPU time holds for 2 s, then 10 s more. Then top reads the memory footprint, then the CPU and wakeups over 60 s.
Disk image
The universal app, packed the way the release build packs it.

The documents come from a fixed generator, the same bytes on every run. They hold headings, inline markup, lists, quotes, code, links, CJK text and emoji.

How a run works

A keystroke is timed in the app being typed in, so perf.sh brings the app to the front. Start it from a terminal and leave the Mac alone until it ends. A run with the app not in front writes no result.

The keystroke tests run three times, each with a clock probe. A run whose clock reads 1.5 times the fastest, or that landed on an efficiency core too often, runs again.

# measure this Mac; writes perf/<version>.json with each budget's result
$ scripts/perf.sh
# judge a result against the current ceilings, as the release workflow does
$ scripts/perf-gate.sh perf/0.1.0.json v0.1.0
