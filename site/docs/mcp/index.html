MCP server

dewline mcp gives an agent one folder of your notes to read, search and trace backlinks in. It can also see your Keep and Revert decisions and add to your inbox.

Add it to your agent

The agent starts the server with your notes folder as its one argument and talks to it over stdio. Use full paths for the command and the folder. The examples serve /Users/you/Notes.

Claude Code

$ claude mcp add dewline -- /Applications/Dewline.app/Contents/Helpers/dewline mcp /Users/you/Notes

That adds it to the current project. Add --scope user after add to make it available in every project.

Codex

[mcp_servers.dewline]
command = "/Applications/Dewline.app/Contents/Helpers/dewline"
args = ["mcp", "/Users/you/Notes"]

Cursor

{
  "mcpServers": {
    "dewline": {
      "command": "/Applications/Dewline.app/Contents/Helpers/dewline",
      "args": ["mcp", "/Users/you/Notes"]
    }
  }
}

Note

These were checked on 2 November 2026 against Claude Code 2.1.317 and that day's Codex and Cursor. If a config format moves, the command stays dewline mcp <folder>.

To serve a second folder, add a second server with another name. Each server sees only its own folder.

What the server can reach

Every path goes through one jail. It resolves every symlink and requires the result to lie inside the folder. Then it opens the file from the folder with no symlink allowed on the way. A link swapped in between the two steps opens nothing.

  • The folder. The server won't start on your home folder or a folder that holds it. Nor will it start inside ~/Library, or on a folder that holds or sits in .ssh. The checks ignore case.
  • File types. Only .md, .markdown and .txt files, in any case. Everything else is refused.
  • Dotfiles. Never a file whose name starts with a dot, and nothing under a dot folder such as .git or .obsidian.
  • Size and text. A file of at most 8 MB, in UTF-8.
  • Search and backlinks. They walk the folder in name order, skip symlinks, read at most 20,000 files and return at most 200 lines. Each line is trimmed and cut at 240 characters.
  • Writes. One: append_to_inbox adds an entry to your inbox. Nothing else on disk changes.
  • Decisions. Only decisions on files inside the folder, with paths relative to it, so the log can't leak paths from elsewhere.

Protocol

JSON-RPC 2.0 on stdio, one message per line. The server answers initialize, ping, tools/list and tools/call, and sends nothing back for a notification. It speaks MCP 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05. It answers with the version the client asks for when it knows it, and with 2025-11-25 otherwise. It offers tools and nothing else.

// request
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"example","version":"1.0"}}}
// response
{"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2025-06-18","capabilities":{"tools":{}},"serverInfo":{"name":"dewline","version":"0.1.0"}}}

The examples ran against a scratch folder holding projects/launch-plan.md, journal/2026-11-02.md, reading.md, todo.txt, page.html and .obsidian/app.md. The server writes each response on one line.

Tools

ToolInputReturns
readpathThe note's text.
searchqueryMatching lines as path:line: text.
backlinksnoteLines that link to the note, as path:line: text.
decisionssession, since, both optionalYour Keep and Revert decisions, as a JSON array.
append_to_inboxtextAdded to the inbox.

Every tool answers with one text item and an isError flag. read shows the whole response; the others show the request and the text.

read

Reads a note: a .md, .markdown or .txt file in the folder. A symlink works when it resolves inside the folder.

Input schema 
{
  "type": "object",
  "properties": {
    "path": {"type": "string", "description": "The note's path, relative to the folder"}
  },
  "required": ["path"]
}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"read","arguments":{"path":"projects/launch-plan.md"}}}
Full response 
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "# Launch plan\n\nShip 0.1.0 on Friday when the signed DMG passes notarization.\n\n## Goals\n\n- Open any folder of Markdown files.\n- Save every file exactly as written.\n"
      }
    ],
    "isError": false
  }
}

search

Finds the lines in the folder's notes that hold the text, ignoring case. The query is a plain substring, not a pattern. An empty query is an error, and no match returns No matches.

Input schema 
{
  "type": "object",
  "properties": {
    "query": {"type": "string", "description": "The text to find"}
  },
  "required": ["query"]
}
{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"search","arguments":{"query":"notarization"}}}
journal/2026-11-02.md:3: Reviewed the [[launch-plan]] with Sam. Notarization is the last step.
projects/launch-plan.md:3: Ship 0.1.0 on Friday when the signed DMG passes notarization.

backlinks

Finds the lines in the folder's notes that link to a note.

  • A [[wikilink]] counts when it names the note's folder-relative path or file name. The extension, case, and anything after | or # don't matter.
  • A Markdown link counts when its path, relative to the linking note, reaches the note. %20 escapes and <angle brackets> work.
  • URLs and absolute paths don't count.
Input schema 
{
  "type": "object",
  "properties": {
    "note": {"type": "string", "description": "The note's path, relative to the folder"}
  },
  "required": ["note"]
}
{"jsonrpc":"2.0","id":5,"method":"tools/call","params":{"name":"backlinks","arguments":{"note":"projects/launch-plan.md"}}}
journal/2026-11-02.md:3: Reviewed the [[launch-plan]] with Sam. Notarization is the last step.
reading.md:3: - See [the plan](projects/launch-plan.md#goals) before the review.

decisions

Lists the agent changes you kept or reverted, oldest first, as a JSON array. It reads the same log as dewline changes, keeping only files inside the folder, with relative paths. An agent calls it so it doesn't redo a change you reverted.

Input schema 
{
  "type": "object",
  "properties": {
    "session": {"type": "string", "description": "Only this agent session's decisions"},
    "since": {"type": "string", "description": "Only decisions at or after this UTC time: 2026-10-30, 2026-10-30T18:00:00Z"}
  }
}
{"jsonrpc":"2.0","id":6,"method":"tools/call","params":{"name":"decisions","arguments":{}}}
[{"vendor":"claude","session":"9f2c51e0-demo","file":"projects/launch-plan.md","time":"2026-11-02T17:42:10Z","decision":"kept","excerpt_hash":"b8bd7e533ca4a32f8950b88300c840eb8b74fd14a30f4c54c916c7224b5e644a"},{"vendor":"codex","session":"019a3b7e-demo","file":"journal/2026-11-02.md","time":"2026-11-02T17:55:31Z","decision":"reverted","excerpt_hash":"06b3ab1fa61729707eae7ac5eb3e57123519c68a07ce26780b602fb796ad7f69"}]

{"jsonrpc":"2.0","id":7,"method":"tools/call","params":{"name":"decisions","arguments":{"session":"019a3b7e-demo","since":"2026-11-02"}}}
[{"vendor":"codex","session":"019a3b7e-demo","file":"journal/2026-11-02.md","time":"2026-11-02T17:55:31Z","decision":"reverted","excerpt_hash":"06b3ab1fa61729707eae7ac5eb3e57123519c68a07ce26780b602fb796ad7f69"}]

append_to_inbox

Adds a dated entry to the end of your inbox note, marked mcp. It is the only change the server can make. The inbox is the same file dewline capture writes, and it may sit outside the served folder.

Input schema 
{
  "type": "object",
  "properties": {
    "text": {"type": "string", "description": "The entry's markdown"}
  },
  "required": ["text"]
}
{"jsonrpc":"2.0","id":8,"method":"tools/call","params":{"name":"append_to_inbox","arguments":{"text":"Ask Sam to sign off on the launch plan."}}}
Added to the inbox.
2026-11-02 18:22 · mcp
Ask Sam to sign off on the launch plan.

Errors

A tool that fails returns its reason as the text, with "isError": true, so the agent can try again. These came back from the scratch folder:

CallText
read ../.zshrc../.zshrc: it is outside the folder
read a symlink to a file outsideshortcut.md: it is outside the folder
read .obsidian/app.md.obsidian/app.md: only .md, .markdown and .txt files outside dot folders are served
read page.htmlpage.html: only .md, .markdown and .txt files outside dot folders are served
read missing.mdmissing.md: No such file or directory (os error 2)
read with file instead of pathread needs a string `path`
search " "search needs a non-empty query
decisions with since as a numberdecisions takes `since` as a string

A file over 8 MB returns it is not a file of at most 8 MB. A file that isn't UTF-8 returns it is not UTF-8 text.

A message the server can't act on gets a JSON-RPC error instead:

CodeMessageWhen
-32700Parse errorThe line isn't JSON. The reply's id is null.
-32600Invalid RequestThe message has no method.
-32601Method not foundAny method but the four above, such as resources/list.
-32602Unknown tool: writeA tools/call for a tool the server doesn't have.
 
// request
{"jsonrpc":"2.0","id":15,"method":"tools/call","params":{"name":"write","arguments":{"path":"reading.md"}}}
// response
{"jsonrpc":"2.0","id":15,"error":{"code":-32602,"message":"Unknown tool: write"}}
