Reference

URL scheme

Dewline registers dewline://. A link can open a file at a line, export a file as HTML or PDF, or join a shared session. Any app that opens URLs can use one, and so can open in Terminal.

LinkWhat it does
dewline://openOpens a file, with the caret on a line when given.
dewline://exportWrites a file as HTML or PDF with the app's export.
dewline://joinAsks to join someone's live editing session.

dewline://open

dewline://open?path=/Users/you/Notes/projects/launch-plan.md&line=12
path
The file. Required. Follows the path rules.
line
Puts the caret on this line, counting from 1. Optional. A value that isn't a positive whole number is ignored.

The link has no column. For a line and a column, use dewline open FILE:LINE:COLUMN.

dewline://export

dewline://export?path=/Users/you/Notes/reading.md&to=pdf&out=/Users/you/Desktop/reading.pdf
path
The Markdown file to export. Required.
out
Where the export goes. Required. Its extension must match the format: .pdf or .html. The folder must exist.
to
pdf or html, in any case. Optional; the default is pdf.

The app writes the export in the background with its own layout. A link can't write DOCX, and because out must carry the format's extension, a link can't overwrite a file of any other kind. For DOCX, use dewline export --to docx.

dewline://join

dewline://join?node=…&relay=…&addr=…&cap=…

An invite to a live editing session. The host's Copy Invite Link makes one: it carries the host's node id, its relay, its direct addresses and a random 256-bit capability. Opening it asks for the name the host will see, and the host approves you by name. Each link admits one join attempt, whatever the host decides. You never write one by hand. Collaboration covers sessions.

Path rules

open and export pass every path through the same check before they touch it:

  • Percent-encode the path in the query: a space is %20. A leading ~ is your home folder.
  • The path must be absolute once ~ is expanded.
  • Dewline resolves every symlink, and the result must lie inside your home folder.
  • Nothing inside ~/Library, and nothing inside a .ssh folder. These checks ignore case.
  • A file that doesn't exist yet, such as an export's out, needs a folder that does.
