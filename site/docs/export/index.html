Export

Export a note as a PDF, a web page or a Word document. Export reads the text in the window and never changes the Markdown file.

Export from the app

  1. Choose File > Export… (⇧⌘E). A save panel opens, named after the note.
  2. Pick a format in the panel's Format menu: PDF, HTML or Word.
  3. Click Export. The status bar says “Exported “Launch plan.pdf” · Show in Finder”.

Unsaved edits are included. To print instead, choose File > Print… (⌘P).

FormatLookDiagrams and math
PDFYour theme's light version and fonts, on your default paper size, 0.75-inch marginsDiagrams as SVG, math as images
HTMLOne standalone file in your theme, light and dark, following the reader's appearanceDiagrams as SVG, math as images
Word (DOCX)Plain document styles for headings, lists, quotes, tables, footnotes and codeTheir source, as text

What each format keeps

  • Images from inside the note's folder are embedded, up to 20 MB each. HTML takes PNG, JPEG, GIF, WebP and SVG; Word takes PNG, JPEG and GIF.
  • Other images, from the web or outside the folder, are not embedded. HTML keeps their address; Word keeps their alt text.
  • Wikilinks become links in HTML and PDF. In Word they stay as written.
  • Highlights, comments, tags and callouts appear as their source text, such as ==one bag==.
  • Front matter is left out of HTML and PDF.
  • HTML in a note shows as visible text in HTML and PDF. Word drops the tags and keeps the text between them.
Page breaks, fonts and safety

PDF page breaks fall between top-level blocks where one fits. A paragraph, list or table splits only when it is taller than a page.

HTML names your fonts without embedding them, so a reader without a font sees a fallback. The page carries a Content Security Policy that allows no scripts and loads nothing from the network.

PDF is laid out from the same page in a web view that runs no script and follows no link.

Export from the command line

$ dewline export --to html notes.md
$ ls
ferry.png
notes.html
notes.md
$ dewline export --to docx notes.md -o out/notes.docx

dewline export writes HTML and Word without opening the app, and prints nothing on success. Its pages use system fonts and a plain stylesheet instead of your theme. Diagrams and math keep their source.

Preview in Finder

Select a .md file in Finder and press Space. Quick Look shows it as a page in your theme's colors. Like an HTML export, it runs no script and loads nothing from the network. Diagrams and math show their source.
