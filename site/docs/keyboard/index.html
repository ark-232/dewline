Keyboard shortcuts

Every shortcut in Dewline's menu bar, menu by menu. A test reads the menu bar and writes these tables, so they always match the app. Help > Keyboard Shortcuts shows the same list inside Dewline, with a search field.

Some keys work outside the menu bar. They are on the pages for the feature they serve:

  • ↩, ⇥ and ⇧⇥ in a list, and ⌘-click on a link, in Editing, which also has the Vim keys.
  • The prefixes > @ : # ? in Quick Open, in First steps.
  • ⌥ in File > Snapshots, in Files and saves.
