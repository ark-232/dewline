# Security

Report a vulnerability privately through GitHub: open the repository's Security tab and choose **Report a vulnerability**. Please do not open a public issue or pull request for it.

Include the Dewline version (Dewline > About Dewline), the macOS version, and the steps or a file that reproduce the problem.

Disclosure is coordinated over 90 days from the report. The fix ships and the advisory publishes within that window, sooner when the fix is ready. If 90 days pass without a fix, you are free to publish. Reporters are credited by handle in the advisory and the release notes when they agree.

Only the latest release gets fixes. Security fixes ship as critical updates through Sparkle's signed feed, so the app shows them at once; it never restarts on its own.
